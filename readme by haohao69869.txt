How to install:

Download and extract UXM      

1. Unpack the game with UXM (it can take a while)

2. Click on the Patch Option while on UXM

3. Go to Elden Ring/Game/Parts and drop the content of the mod in that folder

4. Launch the game OFFLINE and make it sure that EasyAntiCheat is disabled
