# LootForge: Localization Catalogs

Universal localization catalogs adhering to `[CS-LOCALIZATION]`. UI labels, tooltips, dialogs, and messages are registered here without hardcoded literals in the application source.
Diablo weapon and armor auras have independent localized boolean controls.

## Files

| File | Language | Purpose |
| :--- | :--- | :--- |
| `INDEX.md` | - | Localization catalog directory reference. |
| `en.json` | English (United States) | Default primary string dictionary. |
| `pt_br.json` | Portuguese (Brazil) | Secondary localized dictionary with 100% key parity. |
