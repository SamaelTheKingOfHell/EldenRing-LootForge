# LootForge: Data Knowledge Base

Contains vanilla item references, model ID lookup tables, boss remembrance routing definitions, and multi-language localization catalogs.

## Files

| File | Purpose |
| :--- | :--- |
| `INDEX.md` | Data folder directory reference. |
| `vanilla_models.json` | Catalog mapping FromSoftware 3D model IDs (`XXXX`) to vanilla item names, base param IDs, and armor slots. |
| `loot_routes.json` | Registry of Boss Soul Remembrances, elite enemy lot tables, and merchant shops for loot injection. |
| `localization/` | Multi-language localization dictionaries (`en.json`, `pt_br.json`). |
