# LootForge: User Interface

Cross-platform graphical interface for LootForge featuring a dark Souls-themed aesthetic, drag-and-drop mod importer, interactive loot routing controls, and floating developer console.

## Files & Directories

| File / Folder | Purpose |
| :--- | :--- |
| `INDEX.md` | User interface directory reference. |
| `index.html` | Single-page application structure and glassmorphic card layouts. |
| `css/` | Modern CSS stylesheet and dark Souls visual theme. |
| `js/` | Frontend controllers: application logic, API client, and real-time floating console. |
