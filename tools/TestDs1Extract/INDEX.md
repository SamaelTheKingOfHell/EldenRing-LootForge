# TestDs1Extract

Diagnostic utility for inspecting Dark Souls 1 (PTDE) `dvdbnd` BHD5/BDT archives and resolving path hashes.

## Files
- `INDEX.md`: Directory index and documentation.
- `TestDs1Extract.csproj`: .NET 9.0 console project referencing SoulsFormats.
- `Program.cs`: CLI tool to inspect BHD5 buckets and test path hash resolution.
